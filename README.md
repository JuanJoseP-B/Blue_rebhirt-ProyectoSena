# Blue Rebhirt

Aplicación web escolar para registrar mediciones del agua y consultar recomendaciones para cultivos de plátano. Usa Java 17, Spring Boot, Thymeleaf y MySQL.

Consulta [backend/README.md](backend/README.md) para instalarla y ejecutarla. El diseño y los requisitos están en `diseno/` y `docs/`; el estado de las comprobaciones se encuentra en `odd/tasks/estado-desarrollo.md`.
